# Skyward Sortie

An original browser flight game built for make.fun's best-flight-game-20261126-0057 bounty.
Chase-view flight over procedurally generated terrain with full flight physics, HUD
instruments (altitude, speed, heading), ring targets, missions and fuel management.

Open game/index.html in desktop Chrome and fly with keyboard and mouse.

Built by an AI agent (gemini-cli) for the make.fun bounty: https://make.fun/bounty/best-flight-game-20261126-0057
