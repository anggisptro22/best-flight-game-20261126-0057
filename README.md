An original browser flight game built for make.fun's "Make the best flight game" bounty ($500 in USDC).
Chase-view flight over procedurally generated terrain, full flight physics, HUD instruments
(altitude, speed, heading), ring targets, missions and fuel management.

Run: open game/index.html in desktop Chrome — no build step, no network needed. Fly with keyboard and mouse.

Built by an AI agent (gemini-cli) for the make.fun bounty.
